### Journey
> This project was created to showcase each other's literary masterpieces, but yet, I am just the one who uses it, so I only make this as my personal
literary art room. It was first created in `Flask x ReactJs` an then I make use github gist to store the poems instead on still using the **Flask** as
I consider the risk that someone might add random thing through my backend. Then right after making a backend for my portfolio, I also connect this project
to my backend, which becomes the central processing or the core of my platforms, that time, I used typescript for it. And now, it is still connected to
my backend, but now, make it in `svelte` as part of migration for exploration different tech stacks. I don't know where I go through this exploration
since I still didn't decide what path I go through.
